# Habits Tracker — دفترچه عادت‌ها

اپلیکیشن تک‌صفحه‌ای پیگیری عادت‌ها به زبان فارسی (چیدمان راست‌به‌چپ) — به‌صورت PWA و اپ اندروید آفلاین.

**توسعه‌دهنده:** غدیر سروری (Ghadir Sarvari)
**GitHub:** [@ghadirs405-a11y](https://github.com/ghadirs405-a11y)

## امکانات

- پیگیری عادت‌ها با تقویم و زنجیره استریک
- صفحه کوه و چالش‌های صعود (مسیر قله و مدت چالش)
- دستیار هوشمند با سکانس‌های ۴۵ ثانیه‌ای مخصوص هر صفحه (رباتِ بر اساس عکس کاربر، چهره رو به بیننده)
- دستیار هوشمند آفلاین: بدون اینترنت هم پاسخ می‌دهد و برنامه عادت می‌سازد
- کتابخانه موزیک با ۱۳۲ قطعه‌ی تولیدی هوشمند در ۶ کلکسیون (آرامش، تمرکز، انرژی، خواب، طبیعت، انگیزه) + آپلود شخصی
- دفترچه یادداشت، پروفایل کاربری و آمار پیشرفت
- اپ اندروید کاملاً آفلاین مبتنی بر WebView

## ساختار مخزن

| مسیر | توضیح |
|---|---|
| `public/app.html` | اپ اصلی تک‌فایلی (HTML/CSS/JS) |
| `android/apk-src` | سورس اپ اندروید (WebView + assets) |
| `scripts/` | اسکریپت‌های ساخت، تعمیر و پشتیبان‌گیری |
| `download/` | خروجی‌ها: فایل‌های APK نسخه‌های منتشرشده |
| `upload/` | تصاویر و دارایی‌های ارائه‌شده توسط کاربر |
| `worklog.md` | گزارش کار مرحله‌به‌مرحله پروژه |

## نسخه‌های APK

| نسخه | فایل | توضیح |
|---|---|---|
| v2.0 | `download/habits-tracker-v2.apk` | نسخه پایدار با ظاهر تأییدشده |
| v2.1 | `download/habits-tracker-v3.apk` | HUD و موزیک پلیر |
| v2.2 | `download/habits-tracker-v4.apk` | تقویم شمسی + پروفایل حرفه‌ای |
| v2.3 | `download/habits-tracker-v5.apk` | سکانس‌های ۴۵ثانیه‌ای + ربات عکس + AI آفلاین + موزیک تولیدی |

پوشه `android/sdk` (ابزار ساخت محلی، بیش از ۴۴۰ مگابایت) عمداً از مخزن مستثنی است و در `.gitignore` قرار دارد.

## ساخت APK

سورس در `android/apk-src` کامپایل می‌شود با aapt2 + ECJ + d8 + zipalign + apksigner (بدون نیاز به gradle). اسکریپت‌های مربوطه در `scripts/` موجود است.
